제어 노드 연결 대기
실제 로봇이 즉시 움직입니다.
선택한 단계의 모든 물체를 해당 단계 시작 위치에 배치하고 작업 공간을 비운 뒤 실행하십시오. 각 테스트가 끝나면 프로그램은 종료되지 않고 다시 테스트 대기 상태로 돌아갑니다.
100%
실행 중에도 변경할 수 있습니다.
FULL SEQUENCE

전체 공정

원두 투입부터 최종 드립까지 정상 순서로 실행합니다. 분쇄 회전 수는 위 선택값을 사용합니다.

BEAN DROP

원두 투입

스푼 접근, 파지 확인, 원두 투입, 스푼 반환 동작만 실행합니다.

GRINDER

그라인더

손잡이 파지 확인 후 선택한 회전 수만큼 분쇄 동작을 실행합니다.

DRIPPER IN

필터 투입

분쇄 원두 병을 파지하고 필터 투입 및 외력 확인 과정을 실행합니다.

SPIRAL POUR

스파이럴 드립

주전자 파지부터 보상 내향 스파이럴, 주전자 반환까지 실행합니다.

FINAL DRIP

최종 드립

필터 홀더와 물컵 파지, mug TCP 고정 물 붓기와 반대 J6 복귀를 실행합니다.

GRIPPER OPEN

그리퍼 열기

위에서 선택한 DO 프리셋으로 RG2를 열고 0.5초 동안 정착을 기다립니다. 로봇 관절은 움직이지 않습니다.

GRIPPER CLOSE

그리퍼 닫기

DO1 ON / DO2 OFF 조합으로 RG2를 닫고 0.5초 동안 정착을 기다립니다. 파지 성공 판정 없이 입출력 동작만 시험합니다.
